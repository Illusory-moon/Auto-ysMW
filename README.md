# 千星奇域助手（原神）

用于自动刷取每周「千星奇域」经验的工具：点击开始后，脚本会自动进入奇域、反复通关，直到本周经验刷满。

## 运行前的准备

1. 游戏窗口必须为 **1920×1080**
2. 游戏角色需要位于 **千星奇域大厅**
3. 运行过程中**不要操作鼠标**，让脚本自动完成

## 怎么使用

在项目目录打开终端：

```bash
uv sync
uv run new_gui.py
```

- 点击 **开始千星奇域任务**：自动开始刷取（共 16 次）
- 按 **F5**：随时停止任务（程序窗口不会关闭）
- 按 **F7**：打印当前屏幕上的文字位置（调试用）
- 刷满后程序会自动按 **F1** 展示经验界面，任务自动结束

## 小提示

- 脚本会自动把原神窗口切到前台
- 请务必在**千星奇域大厅**内点击开始，其他界面不要点开始
- 使用期间不要把鼠标移到游戏窗口上
