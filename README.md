# 千星奇域助手（原神）

支持「千星奇域」日常与周常的自动化工具，启动时自动判断**官服 / B服**。日常依次通关两个关卡；周常重复通关 16 次刷取经验。

## 运行前的准备

1. 游戏窗口必须为 **1920×1080**
2. 游戏角色可位于 **千星奇域大厅** 或 **大世界**（脚本会自动识别「前往大厅」，并处理进入的加载动画）
3. 运行过程中**不要操作鼠标**，让脚本自动完成

## 支持的服务器

- **官服 / B服均支持**：脚本启动时会按屏幕右下角 UID 自动识别（UID `> 500000000` 为 B服），并自动适配对应的奇域编号、进入按钮与局内逻辑，无需手动配置。

## 怎么使用

打包版：从 GitHub Releases 下载 Windows 压缩包，完整解压后运行 `Auto-ysMW.exe`，按提示授予管理员权限。保留同目录的 `action/movement.json`。

在项目目录打开终端：

```bash
uv sync
uv run new_gui.py
```

- 在设置中选择「周常」或「日常」并保存，再点击对应的开始按钮；默认周常
- 按 **F5**：随时停止任务（程序窗口不会关闭）
- 按 **F7**：打印当前屏幕上的文字位置（调试用）
- 周常 16 次完成后程序会自动按 **F1** 展示经验界面；日常两关完成后返回大厅并结束

## 日常模式

在设置中选择「日常」并保存，然后点击开始。脚本自动判断服务器，依次完成两关：

1. 搜索挑战关卡（官服 `45694132064`，B服 `7448990007`），点击「开始挑战」。识别到血条后挂机 60 秒，按 Esc，点击「中断挑战」，从结算返回大厅。
2. 重新搜索现有周常关卡，按对应服务器的行走方式通关一次，返回大厅后结束。

首次开始挑战后 60 秒未识别到血条，且「开始挑战」仍可识别时，尝试添加列表中的第一个角色并重新开始一次；再次超时则停止。挂机期间 F5 同样有效。

日常完整流程已通过实机测试。血条局部 OCR 未命中时使用整窗 OCR 兜底，并按血条区域过滤结果。两关之间及结束时等待血条或 Alt+N 确认大厅加载；超时停止并记录日志。空编队补选分支已通过模拟测试，尚未单独实机验证。

## 小提示

- 脚本会自动把原神窗口切到前台
- 请确保角色位于**千星奇域大厅**或**大世界**（脚本会自动处理「前往大厅」过渡）；其他无关界面不要点开始
- 使用期间不要把鼠标移到游戏窗口上
